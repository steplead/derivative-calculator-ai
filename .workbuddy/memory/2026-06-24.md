### 背景
用户要求对 DerivativeCalculatorAI 项目网站做最客观的错漏分析并修复上线。该站点部署在 Cloudflare Pages（Next.js 14 + next-on-pages），通过 push 到 main 触发 GitHub Actions 自动部署。

### 发现的关键问题（按严重度）
1. **SEO 致命**：middleware + turnstile.ts 用 /bot/i, /crawler/i 等模式封禁 Googlebot/Bingbot。
2. **功能致命**：四个核心 API 的 `includeAi` 硬编码 `false`，产品核心步骤讲解消失。
3. **构建致命**：`vercel.json` rewrite API 到不存在的 Python 文件 + 要求 pip install。
4. **用户体验致命**：页面 rate limit 1 req/min 锁死正常用户。
5. **安全配置错误**：allowedHosts 写错域名；每请求 console.log 诊断信息泄露 IP/浪费配额。
6. **输入校验过严**：合法数学表达式（含减号）被误杀。
7. **CI 失败**：pages-action@v1 废弃 + Node.js 20 不满足 wrangler v3 要求。
8. **Cloudflare 边缘层**：4 条 Custom WAF Rules 误杀全站（Block Known Bots / Block No Referer 等）。
