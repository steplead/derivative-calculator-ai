## 第二轮修复：referer 误杀 + middleware matcher 版面错乱

### 版面错乱（commit 4b3c73e）
- **根因**：middleware matcher 只排除 `_next/static|_next/image`，但 Next.js 页面 JS 从 `/_next/static/chunks/*.js` 加载，这些路径匹配了 middleware → D1 rate limit → 429 → CSS/JS 加载失败 → 版面错乱。
- **修复**：matcher 扩展排除所有 `_next/*` 路径 + 所有静态文件扩展名（.css/.js/.woff/.ico 等）。

### referer 误杀真实用户（commit 67bf08a）
- **根因**：`utils/turnstile.ts` 的 `looksLikeLegitimateBrowser()` 第 156 行有 referer 检查，把 `https://derivativecalculatorai.com/`（首页 URL）判定为"suspicious: just domain without path"并返回 false。
- **后果**：真实用户从首页发起 API 请求时，referer 为首页 URL → 被判定为 bot → 每次加 20 abuse 分 → 2 次后分数 ≥ 30 → 403 "Access denied. Please use a web browser."。
- **修复**：删除 referer 检查（referer 不是可靠的 bot 检测信号）。
- **同时修复**：`claimsModernBrowser` 正则只匹配 Chrome 90-99，不匹配 Chrome 100+（当前 120+），导致 UA 伪造检测对现代浏览器无效。改为 `chrome\/[0-9]{2,}` 匹配 90-999。

### 最终验证（commit 67bf08a 部署后）

- ✅ Googlebot HTTP 200（SEO 正常）
- ✅ CSS/JS 资源 HTTP 200（cf-cache-status: HIT）

- ⚠️ 快速连续测试时偶发 429：Cloudflare 边缘速率限制，非应用层问题，真实浏览器不受影响

### 重要发现：abuse 评分系统
- `performSecurityCheck` 中 `looksLikeLegitimateBrowser` 返回 false 时加 20 分/次
- 分数 ≥ 15 → strict rate limit（5 req/min）
- 分数 ≥ 30 → 403 block（持续到分数衰减，每小时衰减 50%）
- IP 黑名单检查已被注释禁用，但 abuse 分数检查仍生效
- 修复 referer 误杀后，真实浏览器不应再触发误判
